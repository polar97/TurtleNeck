동공 인지부하 실험

암산 문제를 소리로 들려주고, 푸는 동안 카메라로 동공 지름을 실시간 인식해 난이도별 변화를 그래프로 보여 줍니다. 기록(CSV)과 선택한 영상은 이 폰 안에만 저장되고 어디로도 전송되지 않습니다.

1. 참가자와 순서

소리가 안 들리면: 아이폰은 옆면 무음 스위치를 끄고 음량 버튼으로 크게, 블루투스 이어폰 연결 확인.

2. 카메라 맞추기와 동공 인식

눈을 점선 안에 크게 맞춘 뒤, 검은 동공을 손가락으로 탭하세요

카메라 화면에서 검은 동공을 탭하세요. 초록 원이 동공 테두리에 맞게 따라다니면 인식 성공입니다.

초록 부분이 동공보다 작으면 → 오른쪽, 갈색 홍채까지 번지면 → 왼쪽. 실험 중에는 바꾸지 마세요.

+ 를 보는 동안 화면이 3초간 하얗게 됩니다. 동공이 작아지면 측정이 제대로 되는 것

화면 밝기를 0~100%로 직접 바꾸거나, 자동(0→25→50→75→100→0%, 각 6초)으로 바꾸며 동공 크기를 실시간으로 봅니다. 밝을수록 작아지면 측정이 되는 것

시험 사진에서 검은 동공과 갈색 홍채의 경계가 보여야 합니다. 경계가 안 보이면 조명을 조금 밝히거나 630 nm 빨간 필터를 렌즈에 대 보세요. 사진의 흰 반사점이 동공을 가리면 조명 위치를 옮기세요.

3. 실험 전 확인

  1. 2번에서 초록 원이 동공을 잘 따라가고, 빛 반사 테스트에서 동공이 작아지는지 확인
  2. 방 조명 고정, 커튼 닫기. 폰 자동 밝기 끄고 밝기를 중간쯤으로 고정
  3. 폰을 거치대에 고정, 턱받침으로 머리 고정 (눈–폰 거리 매번 같게)
  4. 무음 모드 해제, 소리 크기 확인. 알림 끄기 (방해 금지 모드)
  5. 참가자에게: "화면의 + 를 계속 보면서 머릿속으로만 풀고, 답을 소리 내어 말하세요"
  6. 도우미는 참가자가 답을 말하는 순간 화면을 한 번 탭합니다 (왼쪽 아래에 ✓ 표시). 빠른 모드는 이어서 ○/× 만 누르면 자동으로 다음 문제

4. 결과: 동공 크기 변화

난이도별 동공 변화

막대 = 평균, 점 = 문제 하나. 문제 듣기 직전 기준선의 평균 지름 대비 풀이하는 동안 평균 지름이 몇 % 커졌는지.

문제 시작 후 시간에 따른 변화

0초 = 문제 음성 시작. 같은 단계 문제를 모두 평균. 각 문제는 답을 말하고 1초 뒤까지만 사용.

전체 기록

회색 점 = 매 순간 인식된 동공 지름(px), 파란 선 = 0.5초 평활, 색 띠 = 문제 푸는 구간(단계 색). 점이 비는 곳은 깜빡임·인식 실패.

저장

페이지를 닫기 전에 저장하세요. 문제별 기록에 동공 변화(dil_pct)가 들어 있고, 동공 원자료는 초당 약 15번 잰 지름 전체입니다(그래프 다시 그리기용).
