동공 인지부하 실험

암산 문제를 소리로 들려주고, 푸는 동안 눈을 녹화합니다. 영상과 시행 기록(CSV)은 이 폰 안에만 저장되고 어디로도 전송되지 않습니다.

1. 참가자와 순서

소리가 안 들리면: 아이폰은 옆면 무음 스위치를 끄고 음량 버튼으로 크게, 블루투스 이어폰 연결 확인.

2. 카메라 맞추기

눈이 점선 안에 크게 들어오게 폰 거리를 맞추세요

시험 사진에서 검은 동공과 갈색 홍채의 경계가 보여야 합니다. 경계가 안 보이면 조명을 조금 밝히거나 630 nm 빨간 필터를 렌즈에 대 보세요. 사진의 흰 반사점이 동공을 가리면 조명 위치를 옮기세요.

3. 실험 전 확인

  1. 방 조명 고정, 커튼 닫기. 폰 자동 밝기 끄고 밝기를 중간쯤으로 고정
  2. 폰을 거치대에 고정, 턱받침으로 머리 고정 (눈–폰 거리 매번 같게)
  3. 무음 모드 해제, 소리 크기 확인. 알림 끄기 (방해 금지 모드)
  4. 참가자에게: "화면의 + 를 계속 보면서 머릿속으로만 풀고, 답을 소리 내어 말하세요"
  5. 도우미는 참가자가 답을 말하는 순간 화면을 한 번 탭합니다

4. 저장

블록마다 영상 1개가 생깁니다. 영상의 시간(초)과 CSV의 시각이 같은 기준이라, CSV의 t_problem 시각을 영상에서 찾아가면 됩니다. 페이지를 닫기 전에 꼭 저장하세요.

+
들은 답 입력 (도우미)
